# ZEPTO-GROCERY-DASHBOARD

## ZEPTO GROCERY SALES DASHBOARD (Interactive Dashboard created using MS Excel)

Project Objective
Built a Zepto Grocery Sales Analytics Dashboard in Excel to track sales KPIs, analyze outlet performance, understand customer preferences, and support data-driven business decisions.

## DataSet Used:
- <a href="https://github.com/ankittanalytics1/COFFEE-SALES-DASHBOARD/blob/main/COFFEE%20SALES%20DASHBOARD.xlsx(https://github.com/sejal179/ZEPTO-GROCERY-DASHBOARD/blob/main/ZEPTO%20Grocery%20Data%20Excel%20(1).xlsx)"> RAW DATASET </a>

## Business Questions
1.	What is the total sales revenue generated?
2.	What is the average sales per transaction?
3.	How many items were sold?
4.	What is the average customer rating?
5.	How does sales vary by outlet establishment year?
6.	Which outlet size contributes the most sales?
7.	Which outlet location performs best?
8.	Which item categories generate the highest sales?
9.	How does fat content impact sales performance?
10.	Which outlet type has the highest sales and item count?
